# Issue tracker

**Type:** Local markdown

**Location:** `.scratch/<feature>/`

**Description:** Issues live as markdown files under `.scratch/` in this repo. This approach is suitable for solo projects or repos without a remote.

**Workflow:**
- New issues: create a new directory under `.scratch/<feature-name>/` with an issue file
- Update issues: edit the markdown file in the `.scratch/` directory
- Close issues: move the issue file to `.scratch/<feature>/done/` or delete

**CLI:** None required
